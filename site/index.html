    How it works

    After qualifying, the model combines the starting grid with each driver's and team's recent results into a win chance for every driver.

    Each forecast is frozen before the start in a chained, append-only log, so editing an old one breaks the chain. Replays re-make past races from earlier results only and are counted apart from the live record.

    More detail

    Every log record carries a fingerprint of the one before it, and the log is committed to git for a second, independent timestamp. Replays use the final starting grid, including penalties.

    The full evaluation, including the models that were tried and did not help, is in reports/baselines.md.

    Not betting advice. Probabilities describe how often drivers in similar positions have won, not what will happen on Sunday.
